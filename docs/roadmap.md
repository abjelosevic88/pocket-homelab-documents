# Roadmap

What Pocket Documents does not do yet, roughly in the order it might:

- **Two-way changes in the documents folder** (a file renamed or moved there is re-filed here; today the folder follows the app, and only the Inbox feeds back).
- **Script detection per document**: pick Cyrillic or Latin models from what OSD sees on the page instead of running both.
- **Sharing a tag or a saved view** with another account (today: one document at a time).
- **Mail bodies as searchable text next to the attachment** (today: the attachment, or the whole mail as .eml).

Said no to: a message queue, a second database, a job runner outside the binary.
